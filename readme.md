# Kotlin Exploration 🚀

A collection of small projects, notes, and experiments for learning Kotlin from scratch to advanced.

## 🛠 Tech Stack

- **Language:** [Kotlin](https://kotlinlang.org/)
- **UI Framework:** [Jetpack Compose](https://developer.android.com/jetpack/compose)
- **IDE:** Android Studio

## ✍️ Learning Notes

- **Modifiers:** Used for decoration and layout. The order of chaining matters significantly.
- **Scaffold:** A layout structure that provides slots for common UI elements (TopBar, BottomBar) and manages `innerPadding`.
- **Preview:** A powerful tool to visualize UI components in real-time without running the emulator.
